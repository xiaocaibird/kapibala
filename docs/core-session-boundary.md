# 同页面会话请求边界修复

关联 V-AUTH-01 与本轮原始核心修复。源码基线 `9087630`，修复候选 `acb271b9c39f66ed855a0a5a5f14f439d5ba0d7f`；本轮没有改变服务端认证协议或多标签协调策略。

## 机制与修改

请求开始时记录会话代次；只有同一代次内的凭据续期允许自动重试。登录、退出改变代次，旧401不得使用新身份发起重试，旧重试401不得清除新会话，迟到成功结果不得交给新身份页面。续期单飞按会话代次隔离，旧请求finally只能清理自身的任务引用。正常同页面REST/WS共享续期仍保留。

## 验证与边界

新增四个受控响应反例在修改前均失败，修后均通过；当前前端检查102/102、零跳过，构建及前后端类型检查通过。使用实际API客户端和可控fetch响应，未声称浏览器或真实服务复现；未写业务数据库。源码、命令和日志哈希见[结构化证据](evidence/session-boundary-verification.json)。

本修复限制后续客户端行为，不能撤销身份切换前已发出的请求或已经产生的外部效果；也不证明浏览器层迟到Set-Cookie与新登录的协调完整。跨标签续期/身份同步仍属PI-20-b暂缓范围。用户人工验收未执行。
