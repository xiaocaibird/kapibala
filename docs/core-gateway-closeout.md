## CG03：未确认 504 的发送中断

**条款与当前事实。** [原文 2.1](original-interview-question.md#21-消息网关) L59、L67–69 只在明确 504 后承诺 2 秒内落地或可由 404 否定；同一个 clientMsgId 再发会产生第二条。A2 L224–225、总则 L192、A5.8 L264 的任意重启、不漏不重、正常结束强保证因此存在条件缺口。当前已持久 sending 意图，接管后保守标 unknown；没有已知 504 时不设置“超过两秒即可重发”的依据。200 查询/`message_sent` 是成功的正证据；当时一次 404 仅说明查询时未落地，503 不提供效果结论。

**不可区分的两条历史。** H1：业务已记发送意图，但请求尚未到网关就崩溃；网关始终没有消息。H2：网关已收到请求，业务未保存响应即崩溃；恢复查询时尚未落地，稍后才成功。两者本地都只有 sending/unknown、没有已知 504，恢复时都可见 404；原协议未给这种一般响应丢失窗口一个可用于否定的上界。H1 的自动补发对 H2 可能造成两条；H2 的不重发策略会使 H1 长期停留未知。

**保留协议的最小做法。** 继续保留意图、查询/事件正证据收敛与不确定说明；只把明确 504 的规定窗口用于否定重试。无需改公开 deliveryStatus，unknown 已在固定枚举内。G08 证明不盲重发，P10 证明一个 SIGKILL 后可查成功的恢复窗口；已知 504 的 G06/G07/G30 和查询 503 的 G10/P11 不是本项未实现。依据既有测试与源码评估，本轮不重复运行这些历史用例。

**真正闭合的条件和成本。** 需要网关对稳定操作身份提供幂等发送，或提供可证明最终状态（包括最终未执行）的操作查询；仅新增“能按 clientMsgId 查询当前已落地”不够。外部接口必须由协议所有者明确承诺，模拟器不能擅自增加假幂等来证明原题。实现成本包括适配器/持久关联/接管流程调整；验证至少覆盖请求未到达、远端成功响应丢失、延迟落地、并发接管及重复查询/提交。可以保留平台 2.3 的公开枚举/接口，但已超出当前固定外部协议。用户若接受保守暂停，只能关闭“带此限制交付”的决定，不能把原强保证改标满足；是否采用协议扩展仍需具体决定。

## CG04：建群成功但 groupId 未保存

**条款与当前事实。** 原文 L48 的创建仅返回一个新 groupId，L247–248 要求异步建群完成后再通知；总则 L192 要求中断恢复。当前 job 先持久 create_dispatch，只有成功保存 groupId 后才能进行 invite/join/promote。遗留 create_dispatch 标 running+recoveryNote，不重复创建；G18 已覆盖远端成功而本地 INSERT 失败。查询 job 只能观察本地已保存状态；网关没有按本次 job/操作查询创建结果的接口，且不为创建者推 member_joined。

**不可区分的两条历史。** H1：持久 create_dispatch 后、请求发送前崩溃，没有群。H2：远端已创建群，但响应丢失或本地事务失败，群已存在而 groupId 未保存。两者本地状态相同。`GET /groups/:id/members` 需要已知群 ID，不能找回未知 ID；后续其他事件也不保证提供本次创建的唯一关联。重发 create 会在 H2 产生另一个群，不重发则 H1 无法自动完成。

**保留协议的最小做法。** 保留 job、已派发意图和明确待核验说明，阻止盲目 create；不把 unknown 写成完成或未执行。新增任务页面或人工绑定按钮只能辅助处理，不能证明自动恢复保证，亦非本轮授权实施内容。

**真正闭合的条件和成本。** 网关创建需接受稳定 idempotency/operation ID 并返回同一 groupId，或提供按该操作 ID 的权威终态查询。现有平台 POST→jobId 与 GET job 可保持兼容；外部协议/模拟器与恢复实现必须同步调整，并验证创建前崩溃、远端落地后断连、本地事务失败、双实例接管、只创建一群且角色正确。当前仍为协议限制，是否接受偏差或推动具体扩展由用户决定，不以补测试关闭。

## CG07：left 空视图与外部成员保留

**能够观察的事实。** 原文 L158 明确完成 leave-all 后 `left/members=[]`；L301 只要求服务账号退出、群主最后；L302 同时要求本地和网关成员一致。`GET members` 是远端当前全体成员，含非服务账号。当前成功退出所有服务账号后清空本地活动 members，job.state 保存 `gatewayMembersAtCompletion`；G21 证明远端仍可保留外部用户。M07–M11 已覆盖真实 HTTP 的重入、迟到成功响应与查询失败，不能把快照证据说成永久当前成员一致。
