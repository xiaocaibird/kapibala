### C1：媒体下载、保留与清理

原要求是媒体消息自动下载至本地媒体目录，路径记入消息；保留天数可配，默认 30 天；删除文件后不留下无效路径，仍被运行中 Agent 使用的文件不删。

现有接入约定：独立 SUT 使用私有持久绝对目录 `MEDIA_DIR`；同库多实例共享同一物理目录，同库重启保留该目录。迁移包含 `009_media_files.sql`，已有候选目标 schema 为 9；最终提测时重新核对实际迁移集合。

QA 可按原要求独立设计正常下载、缺失/过期来源、失败恢复、到期清理、活动引用、重启及迁移/历史消息兼容的用例。下载实际字节、消息路径和清理后的记录需要相互对应，不能只检查状态字段。`localFilePath` 是服务端路径，不是浏览器下载链接；文件不会因此自动加入模型上下文。分布式对象存储、任意容量保证及附件管理界面不在本轮。

### C2：独立真实模型适配服务

原要求是独立服务保持既有 turn/audit 协议，主后端通过显式设置 `AGENT_URL` 切换。现有服务位于 `apps/gemini-agent/`，使用独占私有 `GEMINI_SESSION_DIR`；默认隔离测试仍使用模拟 Agent，不读取用户本地密钥配置。

待独立覆盖的契约包括 `/agent/turn` 与 `/agent/audit` 的合法/非法输入输出、工具提议及结果续接、会话历史、已完成响应复用、错误和未决轮次。实际工具执行、审计顺序、权限、步数和活动预算仍属于主后端，适配服务不能绕过这些规则。P1-04 的后端限制同样适用于模拟和真实模型。

既有真实提供方验证和当前离线协议测试分开引用。当前没有新增付费调用授权；QA 准备时可使用自有独立协议替身，自测替身不等于真实模型接入通过。后续若真实提供方新证据不可替代，应列明必要范围、凭据接入与费用条件，不能自动使用本机 Key。

已知边界保留：硬崩溃可能留下会话目录的 `owner.lock`，需确认旧进程和目录归属后处置；未决轮返回结果不确定，不盲目重发。该限制不是已豁免的原始恢复条款。P1-05 新留存逻辑会改变 C2 内部实现，需在最终候选上做新的独立影响验证。

## 关键变化及风险输入

以下是研发说明的风险面，供 QA 独立选择场景、断言和取证方式，不构成代写测试用例。

| 主题 | 应保持或排除的错误行为 |
|---|---|
| 迟到响应与编辑身份 | A 提交后改成 B、再改回 A，仍是新修订；切群或切身份后的旧响应不能清新输入。发送失败或未知不能被“草稿保护”改成成功，也不新增自动重发 |
| 序列保存与预检 | 新建窗口实际关闭方式共享脏表单/保存中规则；预检等待期间切群、改模板或变量，旧结果不得再确认。目标摘要绑定冻结载荷；失效 URL 群不自动选首群；运行时角色不足、限流顺延和排期规则不变 |
| 关闭 Agent 的原子性 | 资料/开关的 CAS、取消请求、锁和事件顺序保留；事务失败不能只改成功一半。当前步骤的原结束规则不因抽公共入口而改变 |
| 导航来源 | 来源仅允许合法站内两种入口，非法或缺失来源可返回；加载/失败页面也可离开。来源改变不应错误清除另一个群或运行的提醒 |
| 托管身份新政策 | 保护对象是目标身份，不是执行账号是否在线；等待审计或容量期间身份发生变化时，需要派发前最新事实。拒绝使用既有工具错误契约，不能新增对外错误码。普通外部目标继续通过原开关、审计、权限、预算和未知结果保护 |
| 后台诊断 | 现有 `/api/diagnostics/background` 管理员可读，viewer 不获得敏感数据；真实失败/恢复与当前状态对应。固定类别和保守下一步不泄露异常原文、连接串、正文或 Key，不建议对未知效果盲目重发 |
| 用量留存 | 成功/失败是模型服务调用与输出校验结果，不等于工具执行或业务授权成功；未报告的 token 不推算。缓存复用与实际调用分开；有界队列/文件、关闭、权限、清理及写失败不阻断主业务且可诊断 |
| 查询局部优化 | 保持旧游标有效、快照稳定、同毫秒排序、迟到消息和出站确认改时间的行为；数据库计划改善不能直接当页面速度或生产容量结论 |

用量留存的最终配置名、默认上限、记录字段，以及诊断新增响应字段，在实现和自测稳定后由研发补充实际契约；此时不要求 QA 将尚未冻结的草案字段写死。新增 schema、启动命令或环境变更也在正式提测前逐项对齐。
