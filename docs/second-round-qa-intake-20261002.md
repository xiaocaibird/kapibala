### C1：媒体下载、保留与清理

原要求是媒体消息自动下载至本地媒体目录，路径记入消息；保留天数可配，默认 30 天；删除文件后不留下无效路径，仍被运行中 Agent 使用的文件不删。

现有接入约定：独立 SUT 使用私有持久绝对目录 `MEDIA_DIR`；同库多实例共享同一物理目录，同库重启保留该目录。迁移包含 `009_media_files.sql`，已有候选目标 schema 为 9；最终提测时重新核对实际迁移集合。

QA 可按原要求独立设计正常下载、缺失/过期来源、失败恢复、到期清理、活动引用、重启及迁移/历史消息兼容的用例。下载实际字节、消息路径和清理后的记录需要相互对应，不能只检查状态字段。`localFilePath` 是服务端路径，不是浏览器下载链接；文件不会因此自动加入模型上下文。分布式对象存储、任意容量保证及附件管理界面不在本轮。

### C2：独立真实模型适配服务

原要求是独立服务保持既有 turn/audit 协议，主后端通过显式设置 `AGENT_URL` 切换。现有服务位于 `apps/gemini-agent/`，使用独占私有 `GEMINI_SESSION_DIR`；默认隔离测试仍使用模拟 Agent，不读取用户本地密钥配置。

待独立覆盖的契约包括 `/agent/turn` 与 `/agent/audit` 的合法/非法输入输出、工具提议及结果续接、会话历史、已完成响应复用、错误和未决轮次。实际工具执行、审计顺序、权限、步数和活动预算仍属于主后端，适配服务不能绕过这些规则。P1-04 的后端限制同样适用于模拟和真实模型。

既有真实提供方验证和当前离线协议测试分开引用。当前没有新增付费调用授权；QA 准备时可使用自有独立协议替身，自测替身不等于真实模型接入通过。后续若真实提供方新证据不可替代，应列明必要范围、凭据接入与费用条件，不能自动使用本机 Key。

已知边界保留：硬崩溃可能留下会话目录的 `owner.lock`，需确认旧进程和目录归属后处置；未决轮返回结果不确定，不盲目重发。该限制不是已豁免的原始恢复条款。P1-05 新留存逻辑会改变 C2 内部实现，需在最终候选上做新的独立影响验证。

### 管理员后台诊断

入口保持 `GET /api/diagnostics/background`，需要管理员身份；匿名 401、viewer 403。原字段保留，新增字段位于 `modules[]`：

| 字段 | 实际含义 |
|---|---|
| `tickId` | 最近一次实际调度轮次的 UUID，尚无轮次时为 null |
| `lastFailure` | 最近失败或 null；进程内一份记录，不是持久历史 |
| `lastFailure.reason` | `DATABASE_UNAVAILABLE`、`DATABASE_CONTENTION`、`DATABASE_QUERY_CANCELLED`、`REMOTE_UNAVAILABLE`、`REMOTE_REJECTED`、`INVALID_RESPONSE`、`UNEXPECTED_FAILURE` 之一 |
| `lastFailure.occurredAt` | 捕获轮次失败时的 ISO 时间，不冒充故障最早发生时间 |
| `lastFailure.correlation` | 失败的 `{ module, tickId }`；不生成虚构的群、消息、步骤关联 |
| `lastFailure.recoveredAt` | 失败后首个成功调度轮次时间，尚未恢复为 null |
| `lastFailure.nextStep` / 模块 `nextStep` | 分别为失败当时建议与当前建议；固定安全说明，不返回原始异常或凭据 |

后续 tick 成功只证明调度再次成功，不证明旧业务或未知远端效果已恢复。未启动、禁用后台或无本进程失败记录也不等于全部依赖健康。此轮没有新建诊断页面。

### 托管目标政策及事务职责

`kick_user` 在审计通过的群事务内、以及容量准入和派发意图保存后的实际远端调用前，分别核对最新数据库身份。目标匹配 `accounts.platform_user_id` 或本群非空 `members.account_id` 托管关联时，使用既有 `POLICY_DENIED` 拒绝，不发起 kick；离线或普通角色不解除保护。普通外部目标及独立清群/退群仍遵循原规则。最终数据库检查与远端调用之间没有跨系统原子保证。

关闭 Agent 的群 PATCH 继续由 gateway 持有原群事务，委托 automation 的 `requestGroupAgentCancellation` 更新取消请求；CAS、事件提交和事务回滚保持原行为。新增静态检查只约束已列明的 automation 表及 gateway 字面量 SQL，不是全工程 SQL 数据流证明。

### 模型用量文件与配置

文件为 `${GEMINI_SESSION_DIR}/usage/usage.jsonl`，由同一独占会话目录归属保护；本轮没有新增查询接口或用量页面。

正式 `main` 从进程环境读取下表选项并默认启用；Key 文件不会导入这些配置。编程入口 `createGeminiAgent` 需显式传 `usage:{}` 才启用，不传则不创建用量日志。

| 环境变量 | 默认 | 接受范围及行为 |
|---|---|---|
| `GEMINI_USAGE_ENABLED` | 启用 | 仅字符串 `false` 关闭；关闭不删除旧记录 |
| `GEMINI_USAGE_MAX_RECORDS` | 1000 | 整数 1–10000 |
| `GEMINI_USAGE_MAX_BYTES` | 2097152 | 整数 4096–16777216，按 UTF-8 JSONL 字节 |
| `GEMINI_USAGE_MAX_AGE_DAYS` | 30 | 整数 1–365；启动及写入时清理，不含空闲定时清理 |
