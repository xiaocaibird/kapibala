## 首轮问题

先选择 Q1 的方案评估边界，再分别审查消息、建群、移除成员和 Agent 轮次。两个可选答案：

1. 先限定原协议，逐项找可行恢复路径和确切缺口（建议）。
2. 同时给出最小协议补充草案，对照影响后再决定。

原文明确网关不按 `clientMsgId` 去重；要求网关直接去重会改变基线。一次选择草案方向不等于授权外部协议变更。Agent 相同 `runId` 也不等于原轮响应可重放；成员当前不在群与某次移除操作已成功不是同一种证据。

Q1 已收到明确决定：保持现有外部协议，新增外部能力本次全部不做，仅记录建议；并非批准四类恢复的全部内部实现。

Q6 经完整原文核对：A2规定确认未发送后“可以”重发一次，并非强制；S5要求已落地消息同key复用，也不要求对确定未发送的消息重发。负责人授权按排除外部能力后的明确方向直接执行，因此实施侧选择：保留明确504及其安全等待、新查询404和事务内同次请求核对，再判失败，不再安排可选自动重发。该选择正在补实现与回归，不预填通过；旧持久状态兼容和查询本身耗时仍须验证。Q6不再要求负责人选择是否增加外部时序能力。
