# 独立模型服务遗留锁的人工恢复

2026-10-02。依据冻结产品 `0be8575f326f709fe674e20033843d950385043d` 的源码补充，相关产品源码与本次决定前 main 一致。负责人已按 [D053](decisions.md#d053--第二轮八项遗留的处置与一次定向复验) 接受此人工恢复限制。

**本步骤用于恢复服务对会话目录的独占访问，不判断未决模型调用是否成功，不恢复原未决轮次。** 本轮仅核对源码，没有对演示环境、真实会话目录清锁，也没有执行人工恢复故障演练；说明完备不记为恢复实测通过。

## 操作顺序

1. **停止所有可能访问该目录的实例。** 先暂停上游对该 Agent 的请求，关闭进程管理器、容器编排或开发 watcher 的自动拉起，再停止全部指向同一会话目录的实例并确认退出。优先采用既有优雅停止方式，不能仅停止当前终端进程。
2. **确认准确的目录与归属。** 由原启动配置确定 `GEMINI_SESSION_DIR` 的绝对路径。缺省 `.runtime/gemini-agent` 相对于原启动进程的工作目录，不是当前终端目录。核对所属用户、非符号链接和私有权限：目录0700、会话文件0600。不要对归属不明的路径递归修改权限。
3. **确认遗留锁无人使用。** `owner.lock` 的 PID、nonce、创建时间只是线索：PID不存在不能排除其他主机、容器命名空间或其他实例；PID存在也可能已复用，不能据此直接杀进程。共享目录须协调所有相关运行环境停用。无法确认无人使用，就不处理锁。
4. **先完整备份。** 确认不会重新拉起后，将整个会话目录备份到新的受控私有位置，包含锁、会话JSON、临时文件和usage记录，保留权限与归属并核对备份成功。操作记录只保留必要的目录、处理时间和锁身份，不暴露业务历史或凭据。
5. **仅移走这一份已确认遗留的锁。** 再次核对目录和锁未变化，将准确路径下的 `owner.lock` 移至本次私有备份位置的独立留存文件，避免覆盖已有备份。不要递归删除、使用通配符或修改会话JSON；尤其不能把 `pending` 改成 `failed` / `complete`。锁在操作期间消失、重建或内容变化时停止处理，重新核实实例状态。
6. **单实例启动并核对地址。** 用原会话目录和既有配置仅启动一个实例，确认 ready、新锁与 `/health`。默认使用随机端口时，按实际 ready 地址核对后端 `AGENT_URL`。健康检查仅表示服务存活，不证明原调用已恢复、未计费或业务动作已完成。
7. **保留未决原轮次。** 原 `pending` run 仍返回 `409 TURN_OUTCOME_UNCERTAIN`，不会再次调用模型。不要通过删会话、更换 `runId` 或重发相同逻辑请求来绕过保护。本服务没有远端结果查询或人工提交未决响应的恢复接口；原轮次继续保留，另行核对。

此处不提供自动清锁脚本，因为仅根据锁文件中的本地PID不能可靠证明跨主机、命名空间或共享路径下的独占性。

## 处理后仍可能被拒绝的情况

| 情况 | 当前行为 |
|---|---|
| 锁仍存在或另一个实例已重新取得 | 启动拒绝 `SESSION_DIRECTORY_LOCKED`；创建锁时其他文件系统错误也映射到该码，不能看到它就反复移锁 |
| 会话目录类型、归属或权限不安全 | `SESSION_DIRECTORY_UNSAFE` |
| 原run仍为pending | `409 TURN_OUTCOME_UNCERTAIN`，不调用模型 |
| 非pending会话的工具摘要或历史前缀冲突 | `409 RUN_HISTORY_CONFLICT` |
| 会话文件损坏、归属/权限异常、符号链接或过大 | `503 SESSION_STORE_ERROR` |
| 原complete请求完全相同 | 返回持久化同一响应；不代表未知外部业务效果已得到核实 |

## 静态依据

- [SessionStore.open](../apps/gemini-agent/src/sessions.ts)：私有目录检查，使用 `O_EXCL` / `O_NOFOLLOW` 建锁；没有存活探测或自动到期接管。
- [SessionStore.close](../apps/gemini-agent/src/sessions.ts)：正常关闭时核对完整owner内容才释放锁，不能释放别人的锁。
- [turn处理](../apps/gemini-agent/src/app.ts)：相同complete请求复用；pending直接拒绝；先持久化pending再调用模型，完成持久化后才返回结果。
- [启动入口](../apps/gemini-agent/src/main.ts)：会话路径、loopback随机端口、ready输出与正常信号退出。
