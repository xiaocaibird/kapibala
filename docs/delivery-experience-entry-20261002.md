# 交付体验入口：变更与开发验证

本次只补交付辅助入口与说明。改动保留在独立分支，等待负责人审阅；未合入 main，未切换原有演示或人工走查环境。业务源码、数据库迁移及 QA 目录均保持不变。

## 使用方式

从仓库根目录按 [README](../README.md#快速体验初始环境样例环境与重置) 安装依赖后：

| 目标 | 操作 |
| --- | --- |
| 初始环境 | `npm run dev:isolated` |
| 带基准样例的环境 | `npm run demo:sample` |
| 重置到任一基准 | 在当前启动终端 Ctrl-C，确认清理成功且命令正常退出，再执行所选启动命令 |

等待 `isolated-ready`，使用该条输出的 `urls.web`。样例准备成功前不会发布这个最终入口。两种环境都是临时隔离环境，停止时删除该次数据库、模拟器状态和媒体文件；每次重新生成地址并重新登录。需要保存的体验数据应先导出。

默认使用本地模拟网关和模拟 Agent，不要求真实模型凭据。样例包含 22 个群、120 条历史消息、两份序列模板、一条已完成的序列运行、一条已完成且真实经过模拟发送的 Agent 运行，以及保留外部成员的已退群样例。准备完成后关闭自动化，没有仍在运行的样例任务。

## 保留边界

- 这些是交付入口的开发验证，不是重新执行完整业务验收，也不改变既有 QA 失败、阻塞或已接受偏差。
- 本次在 macOS、本机 Docker、Node 24.21.0、npm 12.1.0 验证，不声明 Windows、远程 Docker 或 Linux 实机已通过。
- 原隔离启动在数据库查询/迁移阶段的等待边界仍保留，详见[隔离启动说明](isolated-local-reproduction.md#边界与失败处理)。本次样例准备自身有请求、轮询、整体超时和中断处理，不能扩展为所有启动故障均已验证。
- 样例模式在本次进程中使用本地开发登录配置和默认 Agent 调用超时；非法的继承媒体配置仍可能造成启动失败，需按错误检查启动环境。
- 样例文件和 manifest 位于本次私有临时目录；manifest 包含数据库凭据，不纳入交付材料。
- 稳定基准指场景与状态一致，不是编号、端口或时间完全相同。当前样例不包含所有故障和异常状态。
