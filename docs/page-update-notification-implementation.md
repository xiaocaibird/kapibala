## 实际实现与复核修正

- `LiveProvider`增加订阅、最后消费序号及认证scope marker；marker只建立进入页面的边界，不推进持久重放游标。资源与时间线成功快照记录请求开始时的序号；失败、旧响应和未完成请求不是确认依据。
- `attention/`共享核心管理当前scope、业务目标候选、静态浏览器提示和相关真实操作。字段事件保留各自原始序号，已确认资料变化不被之后设置事件重新提升。标题/favicon退出时恢复；输入框、无关点击、鼠标移动、自动滚动、仅聚焦都不确认。失焦/隐藏同步作废尚未完成的查看意图，异步刷新或延迟帧不能在重新聚焦后恢复旧确认。实际变化事件保持候选，只有旧式模糊失效事件可按同版本抑制；因此状态A→B→A及REST先于WS重放不会吞掉真实变化。
- 目录复用筛选分支`b6d7743`的`directoryQueryIdentity()`，包含q、order、status、agentEnabled及pageSize，不含cursor。成功第一页证据由控制器持有，筛选切换清空，加载更多/probe不伪造新范围证据。搜索与筛选控件保留DOM，只重建结果提醒scope。目录成员数和活动运行由提交事件的可选directoryChangedFields提供真实投影变化证据，角色/运行步骤等非目录变化明确为空；REST先呈现、WS后到仍保留真实变化。旧粗事件缺少该证据时保留“可能变化”的范围确认，不以同值快照断言没变。
- 小区域及具体行要求对应成功版本完整呈现并发生相关操作。长消息超过窗口或时间线裁剪容器时，展示有限文本摘要并第二次确认。未加载/移出列表的候选，显式成功刷新后展示实际当前结果或空态摘要，再第二次确认；不能仅点击通用提示消除。
- 消息手动POST前生成clientMsgId，仅排除当前标签登记的ID。可选字段与旧请求兼容；出站创建和delivery区分，Agent/序列创建仍参与。资料、成员、账号、Agent步骤ordinal、序列stepIndex及job补充实际字段变化事件，与业务状态在现有事务提交。

基础提交`e1397dd`、`6283b5b`；真实变化与范围证据复核`da5abb4`；页面接入`d7cd0f3`；筛选归并`14cfe17`；消息身份保守修正`3c52d10`；字段/创建边界复核`7beb8fd`；失焦意图复核`791550f`；目录投影适配`896b12f`、事务证据`cdf8642`与聚合保真`ee2a0d9`。不创建数据库迁移，不替换队列、审计、Agent或序列状态机。

## 消息身份与其他限制

网关自己的回流消息可能早于clientMsgId的权威关联结果。只有同群、同发送者、同文本且未关联的出站才构成不确定候选；文本差异只能否定回流可能，绝不用相同文本正向判断“本人消息”。待定消息仍立即按原流程落库、同步时间线和保留原Agent规则。现有投递结果事务会核对记录的依赖ID：权威不同msgId、明确失败或从未尝试发送的取消证明独立时，只补发一次confirmed-created；匹配回流照常归并。解歧事件携带原始attentionCreatedSeq判断是否发生于当前scope，新外层seq仍用于快照覆盖；进页前历史不会因之后确认身份变为新内容。已尝试发送后取消、unknown或缺少证据仍可保持待定，不能证明其独立，不新增后台历史扫描。

提醒只覆盖当前页面生命周期；切路由/实体/查询、退出登录或整页刷新会结束旧scope。scope内按目标合并事件；不同消息身份保留到离开页面，长时间不离开且持续收消息有内存增长成本。没有全站未读计数或阅读回执。

目录未知ID缺少完整筛选前后值时，只能提示“当前群目录可能有变化”；成功范围刷新不声称已遍历所有群。外部序列若在两次现有群快照之间开始并结束、从未成为当前展示run，不新增历史运行追踪；当前实际展示run的步骤与终态按相应事件处理。

浏览器检查证明桌面Chromium中实际执行的场景，不证明OS休眠时调度、所有浏览器、真实网关/模型或全部模态/断线组合。当前必要功能脚本不代表原始C3完整Playwright扩展。用户人工验收仍待进行。
