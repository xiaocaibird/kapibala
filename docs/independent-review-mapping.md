## 来源与状态规则

本轮来源记为 **IR-01**：[审查员](thread://01a0f399-c0a4-7972-a546-06af51a2812a?hostId=local)的独立报告，审查基线为 `fa1baa7d7524bf16f379c9c2837fa8cc9ef0bcac`，本轮分类复核也基于此提交。原报告保留在来源对话，本文仅收录必要摘要与映射。引用使用 **IR-01/R01–R14**，以免混淆既有可靠性报告和测试中的 R 编号。

独立报告自行执行的行为验证仅有 SSE 解析算法内存示例；其余主要为源码调用链或既有证据引用。本轮重新核对原文、源码及既有记录，**没有重跑该示例、测试、浏览器或服务**。下表的“静态确认”不等于运行复现，“待验证”不等于已失败。报告的严重性标签和正式上线意见保留在来源中，不直接转换成原始需求违约或用户实施决定。

同一问题沿用 CG / PI 编号，在其下标明新来源和新场景。已通过的有限场景继续有效；新反例追加审查，不把整个旧条目重置为未完成。一个发现涉及两类要求时分别关联，不能据关联行数计算独立问题数量。
