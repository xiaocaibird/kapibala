## MAN-UX-001 · 操作员能识别阻断、失败与账号/群角色含义

- 需求：R-A6-03、ADD-COPY-01
- 优先级：P2；方法：manual
- 自动化入口：按下面步骤人工执行或先解决阻塞

**前置条件**

1. 产品执行已授权且对应自动化已准备状态夹具
2. 全新隔离浏览器，操作员不先阅读实现说明

**执行步骤**

1. 让操作员查看包含正常和blocked运行的群详情，描述当前可操作状态
2. 查看账号断开/释放说明及群成员角色，说明它们分别控制什么
3. 记录看不懂、误读和需要指导才能完成的具体位置

**预期结果**

1. blocked提示可被正常阅读识别，不仅靠难辨颜色
2. 文案使控制台管理权限与群内账号角色可区分，释放不暗示删除历史
3. 只记录实际观察，不把主观偏好自动升级成未约定UI设计要求

**时序要求**

无额外要求。

**故障注入**

无额外要求。

**取证**

1. 截图与操作者观察记录
2. 页面版本与视口/浏览器

**清理**

1. 关闭本轮浏览器上下文；清理专属夹具

**数据**

```json
{
  "states": [
    "blocked",
    "failed",
    "cancelled",
    "unknown"
  ],
  "roles": [
    "控制台admin",
    "群creator",
    "群admin",
    "群member"
  ]
}
```

## MAN-FOCUS-001 · 真实失焦与浏览器标签标题favicon呈现

- 优先级：P1；方法：manual
- 自动化入口：按下面步骤人工执行或先解决阻塞

**前置条件**

1. 产品执行已授权
2. 目标浏览器已确定，独立QA窗口与专属scope提醒已建立

**执行步骤**

1. 分别用系统操作失焦后注入与当前scope相关的更新
2. 查看浏览器真实标签标题及favicon，再仅恢复焦点

1. 恢复执行后的业务断线补齐仍遵循R-B4-01；记录浏览器实际冻结情况

1. 含浏览器标签栏的屏幕证据
2. 焦点切换/注入/呈现/确认时间记录

1. 恢复基础标题后关闭QA窗口
