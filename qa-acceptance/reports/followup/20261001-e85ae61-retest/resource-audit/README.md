# e85 补充复测资源审计

这里只执行 Docker／OS 只读查询，不创建、停止或删除资源，不读取容器 Env。`capture.py` 每次生成全新时间目录，保存实际命令、退出码、stdout／stderr、仅选取的容器归属／端口／Mounts、用例环境索引和文件 SHA256。

当前真实归属及证据限制见 `mid-execution-review.json`。stream 的 PG 50944、worker 6862、guardian 7131、应用 7143 和专用 suite CLI 已通过端口及父子进程链关联，保存了准确匿名卷；后续只查该精确容器／卷是否消失。仍在执行不代表清理失败。

首轮冒烟已经结束，其原始记录为六份 cleanup failures=[]，十八个已登记 API／Gateway／Agent 端口在复核时无监听；第一次容器快照时已无法取得该轮 Mounts，因此不宣称有完整匿名卷逐一销毁证据。Docker 历史查询也没有返回该轮事件。第一份 observedRuns 元数据的秒边界筛选遗漏已说明，原始文件没有覆盖。

最终在主任务明确全部执行和控制器收尾后再做只读检查；归属不明的并行任务资源不能被算成本批遗留或据此删除。最终资源审计不替代产品验收结果。
