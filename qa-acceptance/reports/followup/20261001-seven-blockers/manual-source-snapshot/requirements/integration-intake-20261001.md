## 待授权的具体动作

`config/integration-plan-993f758.json` 是执行范围提案，**不是授权文件**。它记录目标与子集摘要，批准字段保持空，状态为 `AWAITING_EXECUTION_AUTHORIZATION`。需要实际负责人授权后，才按原规则生成有真实来源、时间和期限的授权记录。

范围为 `developer-preflight / developer-smoke / system`，动作仅为：

- `start-isolated-sut`：迁移及启动本轮独立候选与 QA 协议桩。
- `create-owned-database`：新建专属容器/随机数据库并最终清理。
- `fault-injection`：仅本子集 MSG-001 的网关延迟与重复事件。
- `kill-owned-process`：结束或异常时清理本轮持有的进程；本子集不实施产品崩溃恢复实验。

不用 `browser-automation`，不操作演示，不做上线性能/备份/部署评估。正式业务验收须另发范围与授权。目标/子集变更后重新冻结摘要，不能复用旧批准。

获准后的唯一执行入口（在 QA 根目录运行）：

```sh
npm run preflight -- --suite developer-smoke --target config/target.integration-993f758.json --authorization config/preflight-authorization.local.json
```

结果进入 `reports/preflight/<run-id>/`，保留首个失败和清理状态。只允许得到子集联调结果，不升级为正式业务验收通过。
