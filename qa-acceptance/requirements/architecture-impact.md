## 结论与责任

本批没有新增业务域、业务操作或外部网关/Agent 协议。D036 批准的执行容量语义、序列请求契约、暂时读取恢复、测试装配，是已有工程质量要求的具体化。D037 的 review 合并同意不等于功能人工验收通过。

容量耗尽、没有后续触发、重试边界、取消和预算交错本应由 QA 在初次风险分析时主动考虑。原套件虽覆盖单项规则，但缺少这些组合反例；这属于 QA 覆盖设计不足，不能归因于“新需求”而免于补齐。新增 `ENG-*` 编号只是为批准的质量行为建立可追踪条目，不把质量改进包装成新增业务能力，也不替代原 A/B 编号。

## 技术参数不冒充原始硬指标

- 容量八个执行槽、每次最多等待 50ms、内部返回类型，是当前技术机制。容量专项必须先证明测试确实触达容量拒绝，而非凭“同时开八个请求”或总耗时断言；如果外部证据不足，记录具体适配阻塞。资源上限不自动成为可支持八个业务并发的生产 SLA。
- 当前追加三次读取、250/500/1000ms 退避，以及网络错误和 HTTP 状态分类，是实现侧选择的策略。测试数据可以记录被验候选公开声明的版本化策略来构造反例，但不得声称用户永久要求该次数或精确毫秒。原 B4 的三秒补齐和目录约定刷新要求仍按各自条件验收，不能以“用了退避”放宽。
- 当前名称 1–200、步骤 1–200、文本 1–20000、延迟 0–604800、连续步号和步骤键规则，不能倒写成原 B1 明文。对已批准严格契约的负向校验，区分原文已明确规则、被验版本公开声明的输入策略和仍未定语义。若公开策略缺失或矛盾，保留真实 BLOCKED，不从产品 schema 自动生成期望。
- 采用一份共享 schema 是实现选择。黑盒验证前后端行为一致性并不能证明内部真的共享同一文件；本套件不会为证明结构复用而导入产品 schema 充当裁判。
- 现有 `API-001` 与契约自检 对**响应**允许额外字段，与本批对**序列请求**非法额外字段严格拒绝不冲突。不得把入参规则扩散到全部响应 DTO 或改坏原来的前向兼容检查。

这些边界不新增机械审批。D036 已允许实施侧选择具体实现；候选公开技术策略可按其注明版本做兼容回归。只有改变原业务契约、欠缺可验证规范或涉及原未授权范围时，才记录实际待裁定项。

## 现有测试的误判风险

1. `UI-017/019` 在 `tests/ui/console.spec.ts:624–645,672–695` 持续返回 503，直到错误显示才解除；并非只让一个请求失败，所以不能静态断言“加入自动重试后必然失败”。但若进入新重试机制，解除故障后点击人工重试可能和自动恢复竞态。本轮已将这三条人工恢复用例的持续故障改为不自动重试的 403，以隔离人工入口；暂时 503 的自动恢复由独立 ARC-UI 用例覆盖。原来的列表保留、错误显示及提醒确认预期不变。
2. `UI-029` 在 `tests/ui/console.spec.ts:1042–1083` 持续阻断消息读取，验证错误区域操作不清提醒。其业务期望继续成立；本轮同样改为持续 403 后再解除故障，避免自动退避与手动点击抢先。目录和消息时间线未必使用同一读取机制，不能将所有 GET 的行为默认等同于通用资源读取。
3. `AGENT-026` 的前提是没有在线成员；`AGENT-019/020` 的前提是网关明确返回权限/群主错误。它们继续验证真实业务错误，不得把本地容量耗尽强塞进同一期望。反过来，容量延期也不能吞掉这些真实业务错误。
4. `AGENT-022/025/033` 分别验证取消、60 秒预算和审计重试；这不等于覆盖“已审计、等待容量、政策改变”的交错窗口。必须新增独立组合用例，不能只复跑旧单项便宣布完整。
5. `OPS-001` 的批准负载 profile 与容量语义反例目的不同。生产指标待定不妨碍设计容量拒绝的正确性测试；触达局部容量拒绝也不证明生产吞吐、长稳、WS 背压或公平性。

上述是静态适用性判断，非已复现产品失败。产品用例均须在后续授权执行后才产生 PASS/FAIL。

## 保留的范围与不能关闭的缺口

本批不能关闭原 `R-A5-11` / `CL-01` 的任意时刻恢复强保证。公开观测无法精确定位“容量拒绝与持久 ready 之间”的崩溃窗口时，保留该子场景阻塞及缺少的外部控制证据；未知远端效果仍不得盲重放。

架构基线 `:54` 列出的外部协议/处置流程、事件持久队列、历史增长与新分页、WS 资源隔离、完整诊断、跨模块事务及事件契约，未因本批总结获得无限实施授权。其对原始不变量的风险仍保留，未定生产参数继续映射 `REL-05/06`，不能用本次 QA 补齐宣称这些风险均已消除。

本轮覆盖完整度与剩余子场景见 [风险复核](risk-coverage-review.md)。
